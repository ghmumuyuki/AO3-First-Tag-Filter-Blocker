# AO3 First Tag Filter & Blocker (AO3 首位 Tag 过滤器 & 屏蔽助手)

**🇨🇳 中文说明**

1. 核心功能：确保喜欢的 CP 或角色处于文章的首位有效 Tag 中，屏蔽其只是配角的作品；同时支持点击折角永久屏蔽特定作品。
2. 使用方法：输入关键词点 ▶ 屏蔽，点 ⏸ 恢复；点击卡片右上角折角即可永久屏蔽，并在设置页管理。
3. 工作原理：自动屏蔽仅在列表页生效，过滤时仅检查首个有效 Tag（自动跳过分级、警告和 Fandom）；手动屏蔽时，通过记录该作品的唯一 ID 存入本地，实现永久隐藏。本插件只基于原站当前的搜索及过滤结果生效。


---

**🇬🇧 English Description**

1. Core Function: Ensures your favorite ship or character is the first valid tag, blocking fics where they are just side characters; also supports permanent blocking via the folded corner.
2. How to Use: Enter keywords, click ▶ to block, ⏸ to restore; click the top-right folded corner to permanently block and manage in settings.
3. How it Works: Auto-blocking only works on list pages. Filtering checks the first valid tag (skipping ratings, warnings, and fandoms); manual block records the work's unique ID locally for permanent hiding.This script only applies to the search and filter results currently displayed on the original site.
